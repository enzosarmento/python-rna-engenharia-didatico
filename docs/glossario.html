Glossário de Programação, Dados e Redes Neurais

Definições dos termos técnicos de Python, Ciência de Dados e Redes Neurais Artificiais que aparecem nos notebooks, com a fórmula ou um exemplo de uso sempre que ajudam a entender o conceito.

1. Fundamentos de Python e Programação

Elementos da linguagem usados em todos os notebooks.

Variável (x = 10)

Nome que aponta para um valor guardado na memória do computador. O valor pode ser um número inteiro (int), decimal (float), texto (str) ou lógico (True/False) e pode ser substituído a qualquer momento. Em Python, o sinal = significa atribuição ("guarde o valor da direita no nome da esquerda"), e não igualdade matemática; para comparar dois valores usa-se ==. Por isso x = x + 1 é válido: calcula x + 1 e guarda o resultado de volta em x.

Lista ([10, 20, 30])

Coleção ordenada e mutável de valores, escrita entre colchetes e separada por vírgulas. Os elementos podem ter tipos diferentes e são acessados pelo índice, que começa em 0: lista[0] é o primeiro elemento e lista[-1] o último. É possível adicionar (append), remover e extrair trechos (fatiamento): lista[1:3] retorna os elementos das posições 1 e 2.

Dicionário ({'material': 'ABS', 'temp': 230})

Coleção de pares chave: valor, escrita entre chaves. Em vez de acessar pela posição, acessa-se pelo nome da chave: ficha['material'] retorna 'ABS'. As chaves são únicas — atribuir um valor a uma chave já existente substitui o anterior. É útil para agrupar propriedades de um mesmo item ou parâmetros de configuração de um modelo.

Indentação (recuo de 4 espaços)

Espaços no início da linha que definem quais comandos pertencem a um bloco (if, for, while, def, class). Python não usa chaves {} nem palavras como end para delimitar blocos: tudo o que estiver recuado depois dos dois-pontos : faz parte do bloco. Recuos inconsistentes geram IndentationError ou, pior, mudam silenciosamente a lógica do programa (por exemplo, um comando que deveria rodar uma vez passa a rodar dentro do laço).

Laços for e while

Estruturas de repetição. O for executa o mesmo bloco uma vez para cada elemento de uma sequência (lista, faixa de números, linhas de uma tabela): for i in range(5): repete o bloco com i valendo 0, 1, 2, 3 e 4. O while repete enquanto uma condição for verdadeira — é o que se usa no treinamento de redes quando o critério de parada é atingir um erro mínimo. Um while cuja condição nunca se torna falsa causa um laço infinito.

Função (def)

Bloco de código nomeado e reutilizável. Recebe valores de entrada (parâmetros), executa instruções e devolve um resultado com return. Funções evitam repetir código e facilitam testes: def area_circulo(r): return 3.1416 * r2. Variáveis criadas dentro de uma função existem apenas ali (escopo local**) e desaparecem quando ela termina.

Classe (class) e Objeto

Uma classe é um modelo que agrupa dados (atributos) e as funções que operam sobre eles (métodos). Um objeto (ou instância) é um exemplar concreto criado a partir da classe, com seus próprios valores de atributos. O método especial __init__ é executado na criação do objeto para inicializá-lo, e self refere-se ao próprio objeto dentro dos métodos. Ex.: mlp = MLP(n_ocultos=10) cria um objeto; mlp.treinar(X, d) chama um de seus métodos.

Biblioteca / Módulo (import)

Conjunto de funções e classes prontas, escritas e testadas por outras pessoas. import numpy as np carrega a biblioteca NumPy e cria o apelido np, de modo que suas funções sejam chamadas como np.mean(...). Bibliotecas externas precisam ser instaladas antes de importadas (com pip ou conda); as usadas neste curso estão listadas no arquivo requirements.txt.

2. Estruturas e Pré-processamento de Dados

Como os dados são representados, inspecionados e preparados antes de treinar um modelo.

CSV (Comma-Separated Values)

Arquivo de texto puro que representa uma tabela: cada linha é um registro (uma amostra ou ensaio) e os valores das colunas são separados por um delimitador, geralmente vírgula , ou ponto e vírgula ;. A primeira linha costuma conter os nomes das colunas (cabeçalho). Pode ser aberto no Excel ou em qualquer editor de texto e é lido pelo pandas com pd.read_csv(); os parâmetros sep=';' e decimal=',' tratam arquivos no padrão brasileiro.

Array / ndarray (NumPy)

Estrutura central do NumPy para armazenar vetores (1D), matrizes (2D) ou tensores (3D ou mais). Diferente da lista Python, todos os elementos têm o mesmo tipo e ficam contíguos na memória, o que torna as operações matemáticas muito mais rápidas. Atributos importantes: .shape (dimensões — (50, 3) significa 50 linhas e 3 colunas), .ndim (número de eixos) e .dtype (tipo dos elementos).

Vetorização e Broadcasting

Vetorização é escrever operações sobre arrays inteiros em vez de percorrer elemento por elemento com for (ex.: kelvin = celsius + 273.15 converte todos os valores de uma vez). Broadcasting é a regra do NumPy que permite operar arrays de formatos diferentes, "expandindo" automaticamente a dimensão menor: subtrair um vetor de médias de formato (3,) de uma matriz (50, 3) aplica a subtração a cada linha. Funciona quando as dimensões, comparadas da direita para a esquerda, são iguais ou uma delas vale 1; caso contrário, ocorre ValueError.

DataFrame e Series (pandas)

O DataFrame é a tabela do pandas: linhas identificadas por um índice e colunas nomeadas, em que cada coluna pode ter um tipo diferente (números, textos, datas). Uma Series é uma única coluna (ou linha) acompanhada de seu índice, obtida por exemplo com df['idade']. Os métodos head() (primeiras linhas), info() (tipos e valores ausentes) e describe() (estatísticas resumidas) são os primeiros passos para inspecionar uma base.

Feature (entrada, x) e Target (saída desejada, d ou y)

Features (atributos ou variáveis de entrada) são as colunas usadas pelo modelo para fazer a previsão. Target (rótulo ou saída desejada) é a coluna que se quer prever. No aprendizado supervisionado, o modelo aprende a relação entre features e target a partir de exemplos em que ambos são conhecidos e depois aplica essa relação a casos novos. Ex.: no Titanic, classe, sexo e idade são features; Survived é o target.

NaN e Imputação de Dados

NaN (Not a Number) é o marcador usado por NumPy e pandas para indicar um valor ausente. Qualquer conta envolvendo NaN resulta em NaN, por isso esses valores precisam ser tratados antes do treino. As opções são remover linhas ou colunas (dropna()) ou imputar, isto é, preencher a lacuna com uma estimativa (fillna()): média ou mediana para variáveis numéricas e moda (valor mais frequente) para categóricas. A estatística usada na imputação deve ser calculada apenas no conjunto de treino.

Outlier (valor discrepante)

Observação muito distante do padrão do restante dos dados. Pode ser um valor real, porém raro, ou um erro de medição ou digitação. Um critério comum de detecção é o do intervalo interquartil (IQR = Q3 − Q1): são considerados outliers os valores abaixo de Q1 − 1,5·IQR ou acima de Q3 + 1,5·IQR, que aparecem como pontos isolados além das hastes de um boxplot. Como distorcem médias e o treinamento, a decisão de remover, corrigir ou manter um outlier deve ser justificada.

One-Hot Encoding

Técnica para converter uma variável categórica sem ordem natural em números. Cria-se uma coluna binária para cada categoria, com 1 na categoria presente e 0 nas demais: A = [1, 0, 0], B = [0, 1, 0], C = [0, 0, 1]. Isso evita que o modelo interprete códigos como 1, 2, 3 como quantidades (como se C valesse o triplo de A). Também é a forma usada para representar a saída desejada em redes de classificação multiclasse. No pandas: pd.get_dummies(); no scikit-learn: OneHotEncoder.

Normalização (Min-Max) e Padronização (Z-score)

Transformações que colocam as features em escalas comparáveis. A normalização Min-Max mapeia cada coluna para o intervalo [0, 1] com x' = (x − mín) / (máx − mín). A padronização Z-score (StandardScaler) deixa cada coluna com média 0 e desvio padrão 1, via z = (x − μ) / σ. Sem esse cuidado, variáveis com valores numericamente grandes dominam a soma ponderada do neurônio e funções como a sigmóide saturam, deixando o treinamento lento ou instável.

Divisão Treino/Teste e Vazamento de Dados (Data Leakage)

O conjunto de treino é usado para ajustar os pesos; o de teste fica reservado para medir o desempenho em dados nunca vistos (às vezes separa-se também um conjunto de validação para escolher hiperparâmetros). Vazamento de dados ocorre quando alguma informação do teste influencia o treinamento — por exemplo, calcular a média e o desvio do StandardScaler, ou o valor de imputação, usando a tabela inteira antes de separar. O resultado é uma avaliação otimista que não se repete na prática. Regra: separe primeiro, use fit apenas no treino e só transform no teste.

3. Arquitetura de Redes Neurais Artificiais

Componentes de um neurônio artificial e das redes formadas a partir dele.

Perceptron Simples

Modelo de neurônio artificial proposto por Frank Rosenblatt (1958) e a forma mais simples de rede neural: uma única camada de neurônios ligada diretamente às entradas. Calcula a soma ponderada das entradas menos um limiar e aplica uma função degrau, produzindo uma saída binária (ex.: −1 ou +1). É treinado pela regra de aprendizado do Perceptron, que converge com garantia apenas quando as classes são linearmente separáveis.

Pesos Sinápticos (w)

Coeficientes associados a cada entrada do neurônio, que multiplicam o valor dessa entrada antes da soma. O sinal indica o tipo de influência (positivo aumenta o potencial de ativação; negativo diminui) e o módulo indica a intensidade. Os pesos começam com valores aleatórios pequenos e são exatamente os parâmetros ajustados durante o treinamento: "aprender" significa encontrar os valores de pesos que produzem as saídas corretas.

Viés / Bias / Limiar de Ativação (θ)

Termo constante que desloca o potencial de ativação, independentemente das entradas. Sem ele, a fronteira de decisão seria obrigada a passar pela origem — assim como uma reta y = ax sem o coeficiente linear b. No livro-base, é implementado como uma entrada fixa x₀ = −1 multiplicada pelo peso w₀ = θ, o que permite ajustá-lo pela mesma regra de treinamento dos demais pesos. No scikit-learn e no Keras, aparece como intercept_ ou bias, somado (em vez de subtraído) ao potencial.

Potencial de Ativação (u) e Fronteira de Decisão

O potencial de ativação u = Σ wᵢ·xᵢ − θ é o valor calculado pelo neurônio antes da função de ativação. A fronteira de decisão é o conjunto de pontos em que u = 0: uma reta em 2 dimensões, um plano em 3 e um hiperplano em n dimensões. Pontos de um lado da fronteira recebem uma classe; os do outro lado, a outra. Um problema é linearmente separável quando existe uma fronteira reta que divide perfeitamente as classes — é o caso das portas lógicas AND e OR, mas não da XOR, que exige uma rede com camada oculta.

Funções de Ativação

Função g(u) aplicada ao potencial para gerar a saída do neurônio. Degrau: retorna 0/1 ou −1/+1 conforme o sinal de u; como sua derivada é nula, não pode ser usada com Backpropagation. Sigmóide logística, σ(u) = 1 / (1 + e⁻ᵘ): curva suave em forma de "S" entre 0 e 1, derivável em todos os pontos. Tangente hiperbólica (tanh): semelhante à sigmóide, mas entre −1 e 1. ReLU, max(0, u): zera valores negativos e mantém os positivos; é barata de calcular e reduz o problema de gradientes muito pequenos em redes profundas. Softmax: usada na camada de saída de classificação multiclasse, converte o vetor de saídas em probabilidades positivas que somam 1.

PMC / MLP (Perceptron Multicamadas)

Rede com uma camada de entrada, uma ou mais camadas ocultas e uma camada de saída, em que cada neurônio se conecta a todos os neurônios da camada seguinte (rede feedforward totalmente conectada). As funções de ativação não lineares das camadas ocultas permitem representar fronteiras curvas e relações não lineares. O Teorema da Aproximação Universal garante que uma única camada oculta com neurônios suficientes consegue aproximar qualquer função contínua com a precisão desejada. A notação 3-10-1 indica 3 entradas, 10 neurônios ocultos e 1 saída. É treinado com Backpropagation.

TDNN (Time-Delay Neural Network)

Rede com atraso no tempo, usada para prever séries temporais. Um PMC comum não guarda memória entre uma amostra e outra; na TDNN, a entrada é uma janela deslizante com os p valores mais recentes da série, [x(t−1), x(t−2), …, x(t−p)], e a saída é a previsão de x(t). Deslizando a janela um passo de cada vez, a série é transformada em uma tabela comum de entradas e saídas. Para prever vários passos à frente, cada previsão é realimentada como entrada do passo seguinte.

4. Treinamento, Otimização e Métricas

Como os pesos são ajustados e como avaliar a qualidade do modelo obtido.

Época (Epoch)

Uma passagem completa de todas as amostras do conjunto de treino pela rede, com os respectivos ajustes de pesos. O treinamento costuma durar muitas épocas (de dezenas a milhares) e é interrompido quando o erro fica abaixo de uma tolerância (ex.: ε = 10⁻⁶), quando para de diminuir ou quando se atinge um número máximo de épocas. O gráfico de erro × épocas (curva de aprendizado) é a principal ferramenta para acompanhar a convergência.

Aprendizado Online, Mini-Batch e Batch

Definem quantas amostras são processadas antes de cada atualização dos pesos. Online ou estocástico (batch_size = 1): atualiza após cada amostra; é o modo usado nas implementações do livro-base, simples mas com convergência ruidosa. Batch completo: acumula os gradientes de todas as amostras e atualiza uma única vez por época; mais estável, porém lento em bases grandes. Mini-batch (ex.: 16 ou 32 amostras): meio-termo padrão no Keras, que combina estabilidade com a eficiência das operações matriciais.

Regra de Aprendizado do Perceptron (Regra de Hebb)

Regra de ajuste dos pesos do Perceptron: w ← w + η·(d − y)·x, em que d é a saída desejada, y a saída obtida e η a taxa de aprendizado. Se a amostra foi classificada corretamente, d − y = 0 e nada muda; se houve erro, os pesos são deslocados na direção que corrige aquele erro. O processo se repete até que uma época inteira transcorra sem erros. O livro-base chama essa regra de "regra de Hebb" em sentido amplo, embora o postulado original de Hebb (1949) seja não supervisionado.

Erro Quadrático Médio (MSE) e Função de Custo

A função de custo mede o quão distante as saídas da rede estão das desejadas; treinar é minimizá-la. O Erro Quadrático Médio é a média dos quadrados das diferenças entre valor desejado e previsto, E = (1/N)·Σ(d − y)² (o livro-base inclui o fator ½ para simplificar a derivada). Elevar ao quadrado torna todos os erros positivos e penaliza mais os erros grandes. É a função usada em regressão; em classificação multiclasse com Softmax, o padrão é a entropia cruzada (cross-entropy).

Gradiente Descendente e Taxa de Aprendizado (η)

Gradiente descendente é o método de otimização que ajusta os pesos na direção oposta ao gradiente da função de custo (−∇E) — a direção em que o erro diminui mais rapidamente — repetindo o passo até convergir. A taxa de aprendizado η define o tamanho de cada passo: valores muito altos fazem o erro oscilar ou divergir; valores muito baixos tornam a convergência lenta. Valores típicos ficam entre 0,001 e 0,1. Como a superfície de erro de uma rede tem vários vales, o método pode parar em um mínimo local, e por isso treinamentos com pesos iniciais diferentes chegam a resultados diferentes.

Backpropagation (Retropropagação do Erro)

Algoritmo que calcula de forma eficiente o gradiente do erro em relação a todos os pesos de uma rede multicamadas. Funciona em duas fases: na propagação direta (forward), as entradas atravessam a rede e geram a saída e o erro; na retropropagação (backward), a Regra da Cadeia do cálculo diferencial é aplicada da camada de saída em direção às camadas ocultas, obtendo o gradiente local δ de cada neurônio. Com esses gradientes, os pesos são atualizados pelo gradiente descendente. Também é chamado de regra delta generalizada.

Momentum (α) e Otimizador Adam

O Momentum acrescenta à atualização atual uma fração α (tipicamente 0,8 a 0,9) da atualização anterior: ΔW(t) = η·δ·xᵀ + α·ΔW(t−1). Isso acelera o avanço quando os gradientes apontam consistentemente na mesma direção e amortece oscilações, reduzindo o número de épocas necessárias. O Adam (Adaptive Moment Estimation) combina o momentum com uma taxa de aprendizado adaptada individualmente para cada peso, calculada a partir de médias móveis dos gradientes e de seus quadrados; é o otimizador padrão no Keras.

Underfitting, Overfitting e Regularização

Underfitting (subajuste): o modelo é simples demais para capturar o padrão dos dados e erra muito tanto no treino quanto no teste. Overfitting (sobreajuste): o modelo memoriza os detalhes e o ruído do treino, com erro de treino muito baixo e erro de teste alto — comum com poucas amostras e redes grandes. Regularização reúne técnicas para conter o overfitting: a L2 (parâmetro alpha no scikit-learn) penaliza pesos grandes na função de custo; o Dropout desativa aleatoriamente uma fração dos neurônios a cada passo de treino; e a parada antecipada (early stopping) interrompe o treino quando o erro de validação deixa de cair.

Métricas: Acurácia, Matriz de Confusão, MAE, Erro Relativo (%) e R²

Acurácia: fração de classificações corretas (acertos ÷ total); pode enganar quando uma classe é muito mais frequente que as outras. Matriz de confusão: tabela que cruza a classe real com a classe prevista e mostra quais classes são confundidas entre si. MAE (erro absoluto médio): média de |d − y|, na mesma unidade da variável prevista (ex.: ±2,1 MPa). Erro relativo médio (%): média de |d − y| / |d| × 100. R² (coeficiente de determinação): proporção da variância do target explicada pelo modelo; 1 indica ajuste perfeito, 0 equivale a sempre prever a média e valores negativos indicam desempenho pior que isso.
