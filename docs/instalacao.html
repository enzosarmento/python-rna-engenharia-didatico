Preparando sua Bancada Computacional

Se você cursa Engenharia e nunca instalou Python nem abriu um terminal na vida, este guia foi escrito para você. Escolha apenas UMA das três opções abaixo conforme a sua rotina:

Opção 1 • Recomendada para Iniciantes Anaconda + JupyterLab Instalador visual completo que já traz Python, JupyterLab e pacotes científicos prontos. Opção 2 • Leve e Profissional Python Oficial + VS Code (.venv) Ideal para quem prefere o editor Visual Studio Code com ambiente virtual isolado. Opção 3 • Zero Instalação Google Colab no Navegador Perfeito para computadores de laboratório sem permissão de administrador.

Opção 1: Anaconda + JupyterLab (Recomendada)

Mais Simples

O Anaconda é uma distribuição gratuita criada para cientistas e engenheiros. Ao instalá-lo, você recebe automaticamente o Python, o JupyterLab (interface onde abrimos os arquivos .ipynb) e as principais bibliotecas matemáticas (numpy, pandas, matplotlib, seaborn e scikit-learn).

  1. Baixe e instale o Anaconda: acesse anaconda.com/download (clique em Skip registration se desejar), baixe o instalador para Windows, macOS ou Linux e mantenha as opções padrão (Next → Agree → Just Me → Install).
  2. Baixe este repositório: na página do GitHub, clique no botão verde <> Code → Download ZIP e extraia na sua pasta Documentos (ou use git clone abaixo).
  3. Instale o pacote complementar (tensorflow) e abra o JupyterLab: abra o programa Anaconda Prompt no menu Iniciar (ou Terminal no Linux/macOS) e execute:
Anaconda Prompt / Terminal
Bash 
git clone https://github.com/enzosarmento/python-rna-engenharia-didatico.git
cd python-rna-engenharia-didatico
pip install -r requirements.txt
jupyter lab

Uma aba abrirá automaticamente no navegador! Na barra lateral esquerda do JupyterLab, dê duplo clique na pasta documentacao-didatica e abra 00_introducao_python_engenharia.ipynb.

Opção 2: Python Oficial + VS Code + Ambiente Virtual (venv)

Ver requirements.txt ↗
  1. Instale o Python (3.10 a 3.12): baixe em python.org/downloads. Atenção no Windows: marque a caixa Add python.exe to PATH na primeira tela antes de clicar em Install Now.
  2. Instale o VS Code: baixe em code.visualstudio.com e, na aba de Extensões, instale as extensões oficiais Python e Jupyter (Microsoft).
  3. Crie o ambiente virtual isolado (.venv): abra a pasta do repositório no VS Code, abra o terminal integrado (Ctrl + ') e execute:
No Linux / macOS
Terminal Linux/macOS
Bash 
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
No Windows (PowerShell)
PowerShell Windows
PowerShell 
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install --upgrade pip
pip install -r requirements.txt

Ao abrir qualquer notebook .ipynb no VS Code, clique em Select Kernel (canto superior direito) e selecione o ambiente .venv.

Opção 3: Google Colab (Sem Instalar Nada no Computador)

100% em Nuvem

Na página Catálogo de Notebooks deste site, cada um dos 22 cadernos possui um botão laranja Abrir no Colab que carrega o notebook diretamente nos servidores gratuitos do Google!

Dica crucial sobre os arquivos .CSV no Google Colab: Quando você abre apenas um notebook isolado no Colab, as pastas arquivos-csv/ e datasets/ ainda não estão na máquina virtual do Google. Para trazer todas as pastas de dados automaticamente em 3 segundos, crie uma célula no topo do Colab e rode:
Célula Inicial no Google Colab
Colab Magic 
!git clone https://github.com/enzosarmento/python-rna-engenharia-didatico.git
%cd python-rna-engenharia-didatico/documentacao-didatica

Como Operar um Notebook Jupyter (.ipynb)

Pense no Jupyter Notebook como um memorial de cálculo vivo que intercala células de texto (Markdown) e células de código (Python):

  • Executar uma célula: clique dentro do bloco de código e pressione Shift + Enter.
  • A ordem importa! As variáveis criadas na Célula 1 alimentam a Célula 2. Rodar uma célula do meio sem executar as anteriores gera NameError.
  • Reiniciar limpo: use o menu Kernel → Restart Kernel and Run All Cells sempre que quiser reexecutar tudo do início em ordem garantida.
