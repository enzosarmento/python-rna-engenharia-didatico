1. Visão Geral: Da Matemática de Engenharia à IA Sem Caixas-Pretas

Este repositório foi desenvolvido no âmbito do Programa de Iniciação à Docência (PID) com uma missão clara: construir uma ponte direta entre a base matemática da graduação em Engenharia e a Inteligência Artificial aplicada a problemas físicos e industriais.

Em cursos tradicionais de computação, redes neurais costumam ser apresentadas como comandos mágicos — você chama modelo.fit() e recebe um número sem saber quais equações foram resolvidas. Aqui adotamos a metodologia dupla "Caixa Aberta → Ferramenta Industrial":

5. Teoria Simplificada (Com Analogias de Engenharia)

Se você compreende como calibrar um manômetro de bancada ou regular válvulas em uma planta piloto, você já domina a intuição física de uma Rede Neural Artificial. Veja a tradução direta:

5.1. O Neurônio Artificial como uma Estação de Mistura com Válvulas

Um neurônio recebe grandezas medidas pelos sensores (x₁, x₂, …, xₙ), multiplica cada uma por um peso sináptico (w₁, w₂, …, wₙ) e desconta um limiar de ativação (θ, também chamado de viés ou bias), gerando o potencial interno u:

u = ∑ (wᵢ · xᵢ) − θ    ⇒    saída y = g(u)
Pesos (wᵢ) ≈ Abertura de Válvulas

Se w₁ é grande e positivo, a entrada x₁ tem passagem franca; se w₂ ≈ 0, a válvula está fechada (variável irrelevante); se w₃ < 0, atua como inibidor.

Viés (θ) ≈ Parafuso de Offset

Equivale ao ajuste de zero de um sensor: sem θ, toda reta ou plano separador seria obrigado a cruzar a origem (0, 0, …, 0).

Ativação g(u) ≈ Elemento Atuador

No Perceptron, g(u) é um degrau brusco (pressostato on/off). No PMC, usamos curvas suaves deriváveis como Sigmóide (válvula proporcional 0–1) ou ReLU (diodo retificador ideal).

5.2. Normalização de Dados ≈ Adimensionalização

Em Fenômenos de Transporte, nunca misturamos temperatura do bico extrusor (240 °C) com altura de camada (0,06 mm) sem adimensionalizar as escalas — caso contrário, 240 esmagaria numericamente 0,06 e saturaria exponenciais como e⁻ᵘ. Por isso aplicamos Normalização Min-Max ([0, 1]) ou Padronização Z-score (z = (x − μ) / σ).

warning
Regra de Ouro contra Vazamento de Dados (Data Leakage)

A média μ e o desvio padrão σ devem ser calculados exclusivamente no conjunto de treino (fit_transform) e apenas reaplicados nas amostras cegas de teste (transform). Calibrar o escalonador na tabela inteira antes da divisão equivale a calibrar um instrumento usando as próprias amostras secretas da prova de certificação!

pre_processamento_sem_vazamento.py
Python • Padrão Ouro 
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

# 1. Primeiro separamos treino (80%) e teste cego (20%)
X_treino, X_teste, y_treino, y_teste = train_test_split(
    X, y, test_size=0.20, random_state=42
)

# 2. Calibramos média (μ) e desvio (σ) APENAS no conjunto de treino!
scaler = StandardScaler()
X_treino_norm = scaler.fit_transform(X_treino)

# 3. No teste cego aplicamos .transform() sem recalcular estatísticas (Zero Data Leakage)
X_teste_norm = scaler.transform(X_teste)

5.3. Arquitetura Multicamadas (PMC), Backpropagation, Momentum e TDNN

Ao empilhar neurônios em camadas sucessivas conectadas por matrizes de pesos (W⁽¹⁾, W⁽²⁾, W⁽³⁾), formamos o Perceptron Multicamadas (PMC / MLP). "Treinar" essa rede significa resolver um problema de otimização numérica para encontrar os pesos que minimizam o Erro Quadrático Médio (MSE — Mean Squared Error):

E_M = (1 / N) · ∑ ½ · (d⁽ᵏ⁾ − y⁽ᵏ⁾)²
1. Propagação Direta & Backpropagation Os dados entram pelos sensores e geram uma previsão y (Forward Pass). Em seguida, aplicamos a Regra da Cadeia do Cálculo Diferencial de trás para frente (Backpropagation — retropropagação do erro), descobrindo a parcela de culpa (gradiente local δ) de cada válvula intermediária.
2. Gradiente Descendente & Taxa η Como uma esfera buscando o fundo de um vale de energia potencial, ajustamos os pesos no sentido oposto ao gradiente (−∇E). A taxa de aprendizado η regula o passo: η minúsculo demora milhares de épocas (ciclos completos na tabela); η exagerado ricocheteia e diverge.
3. Momentum (α) ≈ Inércia Mecânica Ao somar uma fração α (ex.: 0.8 ou 0.9) do passo anterior ao passo atual (Δw(t) = η·δ·x + α·Δw(t−1)), trocamos uma bolinha de isopor por uma esfera pesada de aço que ganha embalo em rampas suaves e vence pequenos mínimos locais.
4. Janelas TDNN ≈ Filtro Digital FIR Para prever o próximo valor x(t) de um sistema dinâmico, alimentamos a entrada de um PMC com uma janela deslizante de medidas atrasadas [x(t−1), …, x(t−p)], criando uma versão neural não linear de um modelo auto-regressivo.

7. Troubleshooting (Solução de Problemas Comuns)

Apareceu uma mensagem com fundo vermelho ao executar uma célula no Jupyter? Não se assuste: em Python, a última linha do erro informa exatamente a causa. Consulte o guia rápido:

bug_report ModuleNotFoundError: No module named 'numpy'
Causa Mais Provável

As bibliotecas não foram instaladas ou o Jupyter/VS Code está conectado a um Kernel Python diferente daquele onde você executou o pip install.

Como Resolver Imediatamente

No terminal (com o ambiente virtual ativo), rode pip install -r requirements.txt. No canto superior direito do notebook, clique no seletor de Kernel e escolha .venv ou base (Anaconda).

bug_report FileNotFoundError: [Errno 2] No such file or directory: '...csv'
Causa Mais Provável

O diretório de trabalho atual foi alterado ou o arquivo .ipynb foi movido sem a pasta de dados correspondente.

Como Resolver Imediatamente

Mantenha a estrutura original de pastas do repositório. Todos os 22 notebooks já utilizam caminhos relativos validados (ex.: ../arquivos-csv/titanic.csv). No Google Colab, consulte a seção Colab da página de Instalação.

bug_report NameError: name 'df' is not defined (ou 'np' is not defined)
Causa Mais Provável

Você executou uma célula no meio do notebook sem ter rodado as células anteriores (a memória RAM é limpa sempre que o notebook é fechado).

Como Resolver Imediatamente

No menu superior do JupyterLab ou VS Code, clique em Kernel → Restart Kernel and Run All Cells para executar tudo na sequência correta de cima para baixo.

bug_report ValueError: shapes (m, n) and (p, q) not aligned
Causa Mais Provável

Incompatibilidade dimensional na multiplicação matricial (@ ou np.dot): o número de colunas da 1ª matriz (n) precisa coincidir com o número de linhas da 2ª (p).

Como Resolver Imediatamente

Imprima print(A.shape, B.shape) antes do cálculo para inspecionar as dimensões e utilize a matriz transposta .T quando necessário (ex.: X @ W.T).

bug_report ValueError: could not convert string to float / Resultado dando nan
Causa Mais Provável

A planilha ainda possui textos ('male', 'abs', vírgula decimal '3,14') ou células vazias (NaN), ou a taxa de aprendizado η foi alta demais e explodiu as exponenciais.

Como Resolver Imediatamente

Revise a limpeza do módulo 03 (dropna/fillna, codificação numérica e normalização) e reduza a taxa de aprendizado η (por exemplo, de 1.0 para 0.05).

bug_report SyntaxError ou IndentationError
Causa Mais Provável

Faltou fechar parêntese ), colchete ], aspas " ou dois-pontos : após if/for/def, ou o recuo de espaços à esquerda ficou desalinhado.

Como Resolver Imediatamente

Confira a linha indicada pela seta ^ na mensagem de erro e padronize os blocos internos com 4 espaços (tecla Tab).

Causa Mais Provável
